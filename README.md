# Мармеладность

Быстрый перевод текста прямо с экрана. Нажимаешь горячую клавишу, выделяешь область, и рядом появляется маленькое окно с распознанным текстом и переводом. Для отдельных слов показываются словарные значения.

Работает на 64-битной Windows 10 и 11. Платить ни за что не нужно.

## Скачать

**[Скачать Marmeladnost.exe](https://github.com/pumba227/marmeladnost/releases/latest/download/Marmeladnost.exe)**

Устанавливать ничего не нужно, .NET тоже не нужен: файл можно просто запустить. Самый первый запуск занимает несколько секунд, потому что программа распаковывает себя. Положи файл в постоянную папку, если хочешь включить запуск вместе с Windows.

Windows может показать предупреждение «Windows защитила ваш компьютер»: так бывает с любой программой без платной цифровой подписи. Нажми «Подробнее», затем «Выполнить в любом случае».

## Как пользоваться

1. Запусти программу. Значок с таксой появится в трее (он может быть спрятан под стрелкой рядом с часами).
2. Нажми **Alt + Shift + S** и выдели область мышью. Esc или правая кнопка отменяют выделение.
3. Рядом с областью появится перевод. Esc закрывает окно, а Ctrl + C копирует перевод.

Если текст распознался с ошибкой, исправь его прямо в окне: перевод обновится сам. Окно можно перетаскивать за верхнюю часть и закрепить кнопкой с булавкой.

Левая кнопка мыши по значку открывает настройки, правая показывает меню с выходом. Если закрыть настройки, программа останется работать в трее.

## Языки

Язык определяется автоматически. Если текст уже на языке перевода, он переводится на второй язык из настроек.

Распознавание встроено в Windows и умеет только установленные в системе языки, список есть в настройках. Если английский читается с ошибками или текст на другом алфавите не находится, добавь этот язык в Windows: кнопка «Добавить язык в Windows» в настройках открывает нужный раздел.

## Потребление ресурсов

Пока программа ждёт в трее, WPF, распознавание и сеть не загружены, а процессор не используется совсем. Интерфейс загружается при первом нажатии горячей клавиши, поэтому первое выделение после запуска появляется примерно за полсекунды, а следующие примерно за 0,1 секунды. Через 10 секунд после закрытия окон программа сама освобождает память.

## Важно знать

- Перевод идёт через бесплатный неофициальный адрес Google Translate. Если он не отвечает, программа переключается на MyMemory: у него хуже качество и лимит в несколько тысяч символов в день.
- В эти сервисы отправляется только распознанный текст, скриншоты никуда не уходят.
- В играх с эксклюзивным полноэкранным режимом окно выделения может не появиться. В оконном режиме без рамок всё работает.

## Файлы

Настройки и журнал ошибок лежат в `%AppData%\Мармеладность`.

## Сборка

Нужен .NET 10 SDK.

```bash
powershell -ExecutionPolicy Bypass -File publish.ps1
```

Готовый файл появится в папке `dist`. Ему нужен установленный .NET 10 Desktop Runtime. Для компьютера без .NET добавь ключ `-SelfContained`: файл получится больше, зато будет работать сам по себе.

```bash
dotnet test Marmelad.slnx
```

Тесты проверяют логику и настоящее распознавание Windows на отрисованном тексте, поэтому на компьютере должны быть установлены английский и русский языки распознавания.
